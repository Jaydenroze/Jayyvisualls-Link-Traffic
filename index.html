Connect Supabase (Free Real-Time Database)
1
Create a free Supabase account
Go to supabase.com → Sign up free → Create a new project. Pick any name (e.g. "jayyvisualls"). Takes 2 minutes.
→ supabase.com → New Project
2
Create the clicks table
In Supabase → go to SQL Editor → paste and run this:
create table clicks (
  id bigserial primary key,
  link_id text,
  client text,
  platform text,
  type text,
  dest text,
  referrer text,
  ua text,
  ts timestamptz default now()
);

-- Allow public inserts (for tracker page)
alter table clicks enable row level security;
create policy "insert_clicks" on clicks for insert with check (true);
create policy "read_clicks" on clicks for select using (true);
3
Get your API credentials
In Supabase → Project Settings → API → copy your Project URL and anon public key. Paste them below:
4
Update go.html with your credentials
Open go.html in your GitHub repo → edit the two lines at the top with your Supabase URL and key → commit. This makes every link click log automatically.
const SUPABASE_URL = 'https://xxxx.supabase.co';
const SUPABASE_ANON_KEY = 'your-anon-key';
5
Done — your links now track in real time
Every click on a generated link hits go.html → logs to Supabase → your dashboard pulls it automatically every 30 seconds. Pull down on mobile to refresh instantly.
